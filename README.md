# PF Growth redesign prototype

Static, phone-first redesign concept for [Partners for Growth](https://www.pfgrowth.com/). Built for Surface (Shayan Kargarian). **Draft only. Not production. Do not deploy as the live pfgrowth.com site.**

## Open locally

### Option A: open the file
Open this path in a mobile browser or Chrome device toolbar (~390px):

`/workspace/site-builds/pfgrowth-redesign/index.html`

### Option B: simple static server
From this folder:

```bash
cd /workspace/site-builds/pfgrowth-redesign
python3 -m http.server 8765
```

Then visit `http://127.0.0.1:8765/` (or the box host:port if serving remotely).
